# UCKK Math University Projection Contract 1.0.0

This contract specializes `uckk.univers-cite-projection/1.0.0` for MathKristal.

It freezes four boundaries:

1. MathKristal owns mathematical referents, assertions, proof/dependency structure and provenance.
2. The UCKK Math University Projector owns pedagogical selection and topology.
3. SemantiK Architect owns linguistic articulation only; it does not select mathematical content.
4. Moodle owns transactional learning/user state and must preserve it across projection rebuilds.

Machine-readable projection: `local/uckk/atlas/math_university_projection.json`.
Pinned source: `local/uckk/atlas/math_kristal_lock.json`.
Builder: `tools/uckk-ops/kristal/build_math_university_projection.py`.

The projection is rebuildable. A consumer must not infer epistemic authority from the fact that UCKK or Moodle materializes the projection.
