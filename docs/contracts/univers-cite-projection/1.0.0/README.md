# Univers-Cité Projection Contract 1.0.0

This contract freezes the UCKK consumer boundary for scoped knowledge projections. UCKK owns navigation/materialization choices; the source artifact remains the epistemic authority.

For Univers-Cité chrétienne, `primary=people` is a domain choice, not a universal ontology rule. The glossary is `derived_index`: it traverses concepts/themes back to persons, collectives, works, sources and assertions without becoming a second canon.

The current example is intentionally transitional: it pins the existing working Théophile semantic corpus and records a pending migration target to Kristal `5.0.0-rc.3` / Referent Registry `1.0.0`.
