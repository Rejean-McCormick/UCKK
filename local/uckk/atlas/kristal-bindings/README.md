# UCKK → Kristal-Kollection bindings

UCKK no longer owns a local copy of curriculum Kristals. Resolve them from:

```text
%KRISTAL_KOLLECTION_ROOT%\universities\uckk\...
```

Default root on the current workstation:

```text
C:\mycode\Kristal\Kristal-Kollection
```

`manifest.json` maps the 111 stable `kristal_ref` identities to repository-relative paths and SHA-256 digests. `atlas/voies/*.json` remains as the current bootstrap/editorial blueprint and must **not** be deleted.
